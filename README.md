# Devansh Shukla — Premium Animated Portfolio

Code-first portfolio built with Next.js, TypeScript, Tailwind CSS and Framer Motion.

## Visual direction
- Deep navy / charcoal foundation
- Champagne-gold accent
- Editorial typography and cinematic spacing
- Real Devansh Shukla portrait in `/public/devansh-shukla.jpeg`
- Scroll reveals, hover motion, responsive navigation and reduced-motion support
- Data-driven project/certification content for future expansion

## Run locally
```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Build
```bash
npm run build
npm start
```

## Customize
Edit `lib/data.ts` for projects, skills, certifications and social links.
Project case studies live at `app/projects/[slug]/page.tsx` and are generated from the project data.
